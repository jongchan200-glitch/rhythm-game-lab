리듬게임 V18 / 2026-11-23
기준: V17(전체 노트 디자인 개선 + 오늘밤도 HARD 마지막 홀드)의 정식 배포 성공본

사용자 구두 정정이 매우 중요: EASY(기본곡)는 한 곡당 금화 5~6개, HARD는 한 곡당 18~20개. 전체 곡에 18~20개가 아님.

1. 금화는 작은 아이콘이 붙은 일반 노트가 아님. 기존 TAP 입력 위치와 판정 타이밍을 그대로 사용하는 하나의 별도 '금화 형태 노트'다. 기존 TAP 여러 개의 그림을 금화로 대체할 뿐 채보 개수, 점수 만점, BPM, 오디오가 늘어나지 않는다. 게임 화면에서 금색 타원형 입체 디스크와 두툼한 옆면이 레인 폭에 맞춰 내려온다.
2. EASY 5~6개/곡, HARD 18~20개/곡. 곡 ID를 이용한 안정적인 분배 알고리즘으로 매 플레이 같은 위치에서 나온다. 겹치거나 너무 가까운 이벤트를 피하며 음악 전체에 고르게 배치. 실 테스트: 데스매치 6, 월광E 5, 오늘밤도E 6, 월광H 18, 오늘밤도H 18.
3. PERFECT로 TAP 성공한 금화만 획득(기본 +1). GOOD/GREAT/BAD/MISS와 자동 시연에는 0개. 금화는 판정선에서 별도 3D 애니메이션을 시작하여 회전하며 게임 화면 상단 골드 지갑으로 이동. 지갑에 닿을 때 보유 수량이 +1 증가하고 순간 반짝임 +1 표시. 메달 비행이 끝나기 전 숫자는 변하지 않음.
4. 잔액은 localStorage 키 rhythm_lab_coins_v1 에만 저장. 기존 기록 키 moonlight_demo_records_v1 및 채보/설정 키 완전 보존. 홈 EASY/HARD 코인 헤더도 동기화, 코인 패널의 보유액과 PERFECT 획득 설명을 진실에 맞게 변경. 상점 구매, 광고, 결제 시스템은 아직 없음. 새 코인은 미래 상점용 재화로 축적 가능.
5. HARD 에너지바: V7 addon에는 이미 난이도 4/5 에너지 설정이 있었으나 isEasy() 분기에서 HARD를 무시하고 meter.hidden=true로 처리하던 버그를 수정. HARD도 EASY처럼 100% 시작, PERFECT/GREAT 차등 회복, GOOD 유지, BAD/MISS 에너지 차감, 0이면 GAME OVER. HARD 5성은 PERFECT +0.3, GREAT +0.1, BAD -18, MISS -30. 별 4성은 PERFECT +0.5, GREAT +0.2, BAD -13, MISS -22. 실화면에는 여전히 얇은 상단 바(수치 텍스트 없는 디자인)로 표시.
6. V7 EASY 전용 별도 타임라인/연습 UI는 여전히 HARD에서 숨기고 일반 V17 노트 그래픽과 HARD 홈은 그대로. V11+V7 의도치 않은 정상노트 이중 타격음 문제도 이번 통합 시 수정하여 BAD만 수동 1회, GOOD 이상은 기본 원본 엔진 1회.
7. QA: Chromium 390x844 + 기존 5곡 전부 난이도별 배치 수 검사. HARD 에너지 MISS 2연속 100→70→40, 4연속→0 및 GAME OVER. PERFECT 코인 비행 전 0/도착 후 1; GREAT는 0; 자동연주는 0. 홈 지갑과 게임 지갑 일치. JS 문법 검사 3개. 실제 갤럭시 손맛/성능 최종 검수 전.
8. 배포 방식: 기존 V12→V17 GitHub Pages 조립 후 overrides/coin-v18/coin-v18.js,coin-v18.css 를 _site/scripts 로 복사하고 install_coin_v18.py를 실행, 마지막 CI 검증. core/메인 JS의 그리기 부분만 변경, addon의 HARD 상태 분기만 수정, HOME의 코인 패널 텍스트만 변경. 기존 MP3, 5개 JSON 채보, 전체 기록/잔액 초기화 없음. 리소스 URL ?v18 버전 갱신.
9. 사용자가 게임 계속 플레이하며 코인 위치와 HARD 실패 난이도, 표시창 및 지갑 애니메이션을 직접 평가할 예정. 상점 구매 기능은 추가 승인/가격 정책 전까지 구현하지 않음.
