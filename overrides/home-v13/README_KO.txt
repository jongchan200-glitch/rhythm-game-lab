리듬게임 홈 V13 / 2026-11-23

개발 목적
- 사용자 요청: 홈 화면이 너무 복잡하므로 초기 느낌처럼 음악을 좌우로 넘겨 간편하게 선택한다.
- 지옥낙하 실제 홈의 구조(상단 프로필/지갑, 가운데 주인공, 하단 요약/큰 시작 버튼, 최하단 캐릭터/상점/코인/기록/설정 5개 메뉴)를 가져온다.
- 리듬게임에서는 캐릭터 쇼케이스를 레코드 앨범/음악 캐러셀로 바꾸고 블루/금색 계열로 리디자인한다.

구현
- 곡 이전/다음 버튼, 손가락 좌우 스와이프, 곡명/난이도/상세, 미리듣기, 시작, 자동 시연
- 큰 시작 버튼 아래 기록 2개, 맨 아래 5개 고정 내비게이션
- 메뉴 패널: 기본 연주자, 상점 준비, 코인/광고/결제 미연동 안내, 실제 로컬 점수/콤보/횟수, 설정(음악/타격음/진동/연습속도/판정 보정)
- 고급 개발용 음원 추가·채보 편집 기능은 기존 기능 그대로 보존, 설정의 '곡·채보 고급 관리 열기'로 접근
- 지금은 캐릭터/상점/코인 계정 연동, 실재 상품과 지급 기능을 구현하지 않음. UI만 준비.

안전/기술
- 기존 overlay/곡 목록/시작/자동 시연/레코드/설정 입력을 프록시로 연결, 플레이 로직 복제하지 않음
- 기존 데스매치 V12, 월광 EASY/HARD, V11 음높이별 타격음, V10 HUD/에너지 검증 유지
- 설치는 GitHub Actions의 모든 V12 검증이 끝난 뒤 _site HTML/CSS/JS만 추가
- 외부 음원/게임 데이터/로컬 기록은 초기화하지 않음
- 화면 검사: 로컬 headless Chromium 390x844, 360x720, 360x640에서 정상 렌더, 곡 이동/상점/설정 연동 및 고급 관리 열기 확인
