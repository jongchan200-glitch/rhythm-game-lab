리듬게임 V14 홈화면 실제 수정 / 2026-11-23

설계 원본: 사용자 확정 요구 / 2026-11-23 + 03 리듬게임 종합 인수인계 2026-11-20
기준: V13에 지옥낙하식 5개 하단 내비게이션이 이미 설치됨. V14는 홈 화면만 교체함.

1) 전체 화면은 스마트폰처럼 두 독립 페이지
- EASY 홈(첫 화면), HARD 홈(오른쪽에 위치한 잠긴 화면).
- 하단 5개 메뉴는 완전히 고정: 캐릭터 / 상점 / 코인 / 기록 / 설정.
- 하단 위의 상단 프로필, 타이틀, 중앙 앨범, 기록, 큰 시작 버튼이 모두 좌우로 움직임.
- 빈 배경에서 왼쪽 스와이프: HARD / 반대 방향: EASY. 화살표와 설명 문구 없음.
2) EASY 음악 선택
- ★★★ 이하인 실제 준비된 채보만 보임. 4~5성 곡은 EASY 캐러셀에 노출하지 않음.
- 큰 아날로그 LP 음반 내부에 곡 제목과 ★만 표시.
- LP 자체에서만 스와이프하면 음악이 변경되며, 홈 페이지는 안 움직임.
- 곡 아래에는 간단한 트랙 정보, 작사·작곡·원작곡·제작 크레딧 및 미리듣기.
- 데스매치 음악에는 작사·작곡 챨스 / 제작 한울 표기.
- 월광 소나타 음악에는 원작곡 L. van Beethoven / 제작 한울 표기. 베토벤 원작곡자를 챨스로 바꾸지 않음.
3) HARD 홈
- EASY 첫 앨범(데스매치)과 동일 제목을 처음 앨범으로 보여주지만, 매체는 실버/블루 CD.
- 차가운 파란 톤, 잠금 아이콘, HARD LOCKED 표시, 비활성 게임 시작.
- 현재 해금 조건 없음. 추후 곡·채보를 넣고 잠긴 상태 유지하도록 화면 구조 준비.
- 기존 하드 채보/오디오/게임 기록은 삭제하지 않고 기존 고급 관리 기능에 남겨 둠.
4) 기술과 검증
- V13 소스는 저장소에 남기고, 추가 V14 오버라이드 CSS+JS만 실제 HTML에서 교체하여 사용.
- 원래 메인 게임 엔진·음원·자동 시연·기록 저장 키·설정값·보관함을 건드리지 않음.
- Chromium 390x844 / 360x720 / 360x640에서 렌더, LP 스와이프, 빈 영역 페이지 전환, 고정 네비, 상점, 설정 연동 시험.
- Android 터치 스와이프를 에뮬레이터 Chromium CDP touchStart/Move/End로 추가 시험.
- 실제 사용자 Galaxy 확인 전 최종 승인 아님.
