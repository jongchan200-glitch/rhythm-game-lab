데스매치 홀드·릴리즈 V15 (2026-11-23)

목적: 사용자의 '음악에 어울리는 곳이 있으면 한두 개만 넣고, 억지로 넣지 말라'는 요청을 시험한다.

실제 음악 검토: 기존 Google Drive 원본 WAV에서 연속 편집한 데스매치 57.34초 MP3의 스펙트로그램/레벨과 V12 131개 채보를 대조.
26.308초부터 약 28.1초까지 일정한 저음(저음 펄스/롤링 음형)이 유지되고, 해당 0레인 다음 노트가 28.421초인 구간을 한 건 선정.
그 외 짧은 노트 밀집 구간에는 홀드를 넣지 않는다. 음원 자체는 전혀 변경하지 않는다.

변경:
- 원래 V12 131노트 중 26.3082초 레인0, MIDI 54(bass), tap 1개를 kind='hold'로 전환.
- 해당 홀드 종료: 27.980초에 kind='release' 노트 1개 추가, startT=26.308, duration=1.672.
- V15 결과: 총 132개 채점 이벤트 (HOLD 시작 1 + RELEASE 종료 1), 다른 130개 이벤트 변화 없음.
- 사용자 입력: 시작 때 정확하게 누르기, 지속, 마지막에 정확히 떼기. 조기 해제/지연 해제/도중 취소/미입력 MISS.
- 시각: Cyan HOLD 타격 헤드와 길게 이어지는 연주 바. 시작을 눌러도 종료 전까지 길쭉한 바가 남고 점점 줄어듦.
- 모바일 손가락 터치 및 PC D/F/J/K 입력. 다른 레인의 탭/플릭은 기존 동작 그대로.
- 자동 시연: 홀드 시작~종료 동안 버튼 점등을 유지, 끝에서 자동 릴리즈.
- 기존 V7 EASY 에너지 판정, 퍼펙트/그레이트/굿/배드/미스, 점수/콤보와 기록, 기존 월광 두 곡과 HARD 잠금 홈 유지.
- 편집기 검증기에 hold/release 종류와 연결 정보 전달/검증 추가. `sound` 음색/음높이 꼬리표 보존.
- 내장 chart override를 구분하기 위해 manifest.version만 V15로 변경. 이전 사용자 로컬 편집 데이터는 삭제하지 않으나 새 버전의 채보가 우선 로드됨.

검증:
- 실제 WAV/MP3 스펙트럼·노트 간격 검토, local Chromium 렌더/가상 pointer 및 V7 엔진으로 눌림/뗌/일찍 뗌/자동 시연 테스트 통과.
- GitHub Actions에서 원곡 오디오 sha, 노트 수, 달라진 노트 수, 정확한 홀드/릴리즈 시점, 노트 종류, 기존 3곡 유지와 JS 문법 검사.
- 갤럭시 실기기 손맛·릴리즈 판정 정확도·실제 음악에서의 적합성은 사용자 확인 전.
- 사용자가 별로라고 평가하면 V15 patch만 제거해 이전 V14로 복구 가능.
