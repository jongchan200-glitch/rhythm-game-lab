리듬게임 V20 | 「우리 꽤 잘살았네」 EASY/HARD 구간 전면 재편집
2026-11-23

수정 동기: 사용자가 기존 V19 편집(EASY 56.01초: 원곡 53.14~109.15초, HARD 52.45초: 154.23~206.68초)을 실제 플레이하니 시작과 끝이 중간에 잘리는 느낌이 너무 어색하다고 피드백. 이전의 고정 '1분' 목표를 삭제하고 1:20~1:50 내로 음악성 우선. 고음 후렴 클라이맥스에서 곡이 제대로 끝나는 경우는 EASY/HARD가 같은 구간을 공유해도 된다고 명시.

V20 편집:
- 사용자 업로드 '우리 꽤 잘살았네..wav' 원곡 길이 237.20초 (3:57.2).
- 새로운 단 한 구간: 원곡 151.20~237.20초 (2:31.20~3:57.20), 86.0초(1분26초).
- 원곡 뒤쪽 긴 고조, 고음이 올라가는 클라이맥스 및 실제 녹음이 자연스럽게 사라지는 엔딩 포함.
- 앞과 뒤를 자의적으로 여러 구간 합치는 콜라주 없음. 0.16초만 부드러운 페이드인, 마지막은 원곡의 실제 fade/outro를 보존해 인위적인 하드컷 없음.
- EASY/HARD는 **같은 완성된 86초 오디오 1개를 공유**하고, 각각 다른 음표 패턴/난이도를 가짐.
- '151.20초가 정확한 후렴 가사의 첫 음절'이라고 보장하지 않음. 오디오 파형, 온셋, 음량·구간 변화 분석으로 찾은 합리적인 **청취 시험 후보**. 사용자의 갤럭시 실기기로 고음 클라이맥스/시작/끝 귀 검수가 최종이다.

V20 채보:
- 기존 트랙 ID well_lived_easy_v19와 well_lived_hard_v19를 유지하여 기기 내 스코어/플레이 기록을 삭제하지 않음.
- EASY ★★★ 140개 판정 이벤트, 133 TAP + 7 FLICK. EASY 플릭 0,3 외곽 레인만 사용. 동시노트 없음. 107.67 BPM 오디오 트래킹 기반.
- HARD ★★★★★ 246개 판정 이벤트, 201 TAP + 45 FLICK, 동시 2개 맞추기 12회. 원곡의 주요 박자+오프비트 강세에서 채보 생성.
- 새 노트들은 실제 원곡의 onset/beat에 근접 스냅하고 각 노트 음높이/악기 태그를 녹음 FFT에서 추정. 확정적인 보컬 멜로디 스템 분리 채보가 아니며 사용자 손맛/정확한 박자 최종 검수 전.
- 금화 노트 수 기존 V18 자동 규칙: EASY 곡당 5~6, HARD 18~20. 금화 PERFECT만 저장; HARD 에너지 회복/소진 그대로.
- 엔딩 보컬 HOLD를 무작정 넣지 않음. 실제 음절과 지속음의 귀 확인 후 필요할 경우에만 넣는다.
