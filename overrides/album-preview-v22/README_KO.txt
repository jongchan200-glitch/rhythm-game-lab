Rhythm Lab V22 — LP·CD 앨범 스와이프 자동 음악 미리듣기
2026-11-23

현재 기준: V21은 이미 사용자 요청의 「우리 꽤 잘살았네 버전 2」 HARD 앨범을 기존 HARD와 함께 별도로 배포함. V21의 240노트(탭200/플릭40), 학습용 반복 A×8/B×6/C×4 모티프, 총 8곡, 사용자 기록, V18 코인/에너지는 절대 덮어쓰지 않는다.

이번 V22 수정 사항:
1. EASY LP를 손가락으로 좌우 넘기거나 좌우 방향키로 넘기면, 변경된 해당 앨범 음악이 즉시 자동 재생된다.
2. HARD CD를 손가락으로 좌우 넘기거나 좌우 방향키로 넘기면, V21 CD의 선택곡을 실제 catalog에서 선택한 다음 자동 음악 미리듣기가 시작된다.
3. 별도 ‘곡 미리듣기’ 버튼을 누를 필요 없다. 기존 보조 버튼은 재생/멈춤을 선택할 수 있게 유지하고, 텍스트는 “자동 재생 중 · 탭하면 멈춤” 등 실제 상태를 보여준다.
4. 앨범 변경 시 새 오디오를 그 사용자 제스처 안에서 바로 play() 호출하여 브라우저 자동재생 정책과 충돌 가능성을 낮춘다. 서로 다른 음원은 약 210ms로 크로스페이드, 새 곡은 300ms 페이드인. 홈 화면에서는 최대 약 22초 미리듣기 후 잔잔하게 꺼지며 사용자가 다시 재생 가능.
5. V21 버전 2는 실제 반복 드럼 비트가 들리는 8.15초쯤에서 시작하도록 미리듣기 위치만 조절. 본 게임 음악은 항상 원래 86초 시작과 끝을 전부 사용.
6. 게임 시작/자동 시연 버튼, EASY ↔ HARD 홈 화면 전환, 앱 숨김/종료 시 미리듣기 즉시 정지. 본 게임 소리 및 음원 길이·채보 타이밍·저장과 충돌하지 않게 게임과 미리듣기용 Audio 객체를 구분.
7. 브라우저에 따라 음성 출력 허용은 실제 손가락 스와이프 또는 보조 버튼 탭이 필요한 경우가 있다. 오류 시 버튼 안내를 표시.
